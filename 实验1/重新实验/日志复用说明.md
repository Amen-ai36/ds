# 可复算日志与成员复用说明

## 交接文件

- `直连正式数据.csv`：正式公网原始记录，每一行对应一次请求尝试。
- `直连正式运行记录.txt`：同一次运行的控制台输出。
- `直连正式数据-核对/逐行核对表.csv`：原 CSV 行号、重算偏移、重算时延、重算校正时间及 PASS/FAIL。
- `直连正式数据-核对/复算报告.md`：逐条列出 T1–T4 和代入公式的完整过程，包含原日志 SHA-256。
- `故障记录核对/`：本地模拟成功、超时、发送失败、解析失败记录的字段核对；不作为公网精度数据。

## 字段约定

CSV 为 UTF-8，首行为列名。时间戳以 Unix 毫秒表示，与显示时区无关；计时长度单位也为毫秒。未知字段为空，不能当成 0。建议用 CSV 读取器或 Excel 的文本导入功能读取，不能简单按逗号拆分（异常原因可能含逗号）。

| 字段 | 含义与使用约定 |
|---|---|
| request | 本文件内的尝试序号，从 1 开始；不同文件须结合文件名区分 |
| server | 命令行指定的服务器域名或 IP；不是抓包确认的响应 IP |
| status / reason | 成功或失败状态及具体原因；成功必须为 NTP_Success / OK |
| t1_unix_ms | 客户端本次发送前的本地时间 |
| t2_unix_ms | 服务器接收请求时间 |
| t3_unix_ms | 服务器发送响应时间 |
| t4_unix_ms | 客户端收到有效匹配响应后的本地时间 |
| local_unix_ms | 校正前本地时间，成功时等于 T4 |
| corrected_unix_ms | T4 + offset_ms，应用层校正时间 |
| offset_ms | 估计的服务器相对本地时钟偏移；正数表示本地落后 |
| delay_ms | 往返网络时延估计，扣除了服务器处理时间 |
| wait_ms | 使用单调时钟测量的接收等待时间；发送失败时是发送尝试耗时 |
| resolve_ms | 最近一次服务器地址解析耗时；每个请求行重复记录该次解析结果，不应累加成总解析耗时 |
| sent | 是否成功调用 UDP 发送；不代表服务器已收到 |
| discarded_packets | 等待本次响应期间丢弃的无效包总数 |
| origin_mismatch_packets | 上述丢弃包中 Origin 时间戳不匹配的数量 |
| last_discard_reason | 最后一个无效包的丢弃原因；没有丢弃包则为空 |
| request_timestamp_hex | 本次发包的原始 8 字节时间戳，16 个十六进制字符，按文本导入 |
| transport | DIRECT_UDP 表示直连；SOCKS5_UDP@... 表示显式代理通道 |

NTP T2、T3 小数部分四舍五入到毫秒；offset 除以 2 时按 Java 整数规则向零截断（例如 -3/2 = -1），不是向负无穷取整。量化会导致与亚毫秒计算结果存在差异。

wait_ms 与 T4−T1 不必严格相等：前者从成功发送后开始计时，后者含发送前记录时间到接收后的时间，且采用不同计时源。两者不能互相替代。

## 复算公式

```text
offset = trunc_toward_zero(((T2-T1)+(T3-T4))/2)
delay = (T4-T1)-(T3-T2)
corrected = T4+offset
local = T4
```

只对 NTP_Success 行计算统计值。失败行保留在成功率/可用性分析中，但其空白 offset/delay 不参与均值。当前偏移估计不等于经独立标准验证的同步后绝对误差。

## 任意新日志的一键核对

项目根目录执行（只需 Python 3，无第三方依赖）：

```bash
python3 "实验1/tests/audit_ntp_log.py" "实验1/重新实验/直连正式数据.csv"
```

输出目录默认位于原 CSV 旁，命名为 `<文件名>-核对`。也可以指定：

```bash
python3 "实验1/tests/audit_ntp_log.py" "你的日志.csv" --output "你的核对输出目录"
```

退出码 0 表示全行核对通过，1 表示发现不一致，2 表示文件或输入错误。工具逐条检查 T1–T4 公式、原始请求时间戳与 T1 是否一致、状态、原因、耗时、丢弃计数及失败行空值。工具只证明日志内部一致，不能验证响应真实性或历史网络事件。

为了确认工具能发现错误，已另用临时副本将首行 offset 加 1：工具正确报 FAIL，正式 CSV 未改动。

## 重跑和数据一致性

```bash
bash "实验1/重新实验/直连重跑.sh"
```

脚本生成带时间戳的新 CSV/控制台记录，并自动生成对应复算报告。它不自动关闭系统代理；正式直连演示前请确认系统代理已关闭。客户端不设置代理启动参数，transport 应为 DIRECT_UDP。

每份复算报告标明所核对 CSV 的 SHA-256；日志改动后应重新核对并一起交付。原始数据、控制台输出和复算报告应成套保留，不混用不同次运行。

## 给各成员

- A：用逐条复算报告中的真实公网记录核对公式、符号和整数舍入约定。
- C：读取正式 CSV 做正常场景统计；故障记录独立分析，保持采样条件标注，不能混入正常偏移均值。
- D：运行直连脚本展示四时间戳与校正时间；再运行核对命令展示验证结果，公网不通时使用保存记录并注明历史实测。
